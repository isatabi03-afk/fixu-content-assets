# fixu-content-assets

Assets publicos (PNG de slides + PDF de carrusel) de las piezas aprobadas en
`Contenido/pendiente-publicar/`. Existen para que la API de Buffer pueda descargar
la imagen por URL: Buffer no acepta archivos locales.

- Se sincroniza con `Contenido/output/sync_assets.mjs` (nunca a mano).
- Solo entra lo que Santi ya aprobo en el visor. Todo aqui es publico.
- Sirve por GitHub Pages: https://isatabi03-afk.github.io/fixu-content-assets/
